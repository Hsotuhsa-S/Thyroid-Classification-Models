# Comparative Analysis of Thyroid Disease Classification Models

## Project Overview
This repository contains a comparative analysis of different machine learning models for thyroid disease classification. The project was part of the Medical Data Science course at Heidelberg University, focusing on developing and evaluating various classification approaches to identify thyroid disorders.

## Project Background
Thyroid disorders are common medical conditions that can significantly impact a patient's health if left undiagnosed. This project aims to develop reliable classification models that can assist in early detection and diagnosis of thyroid diseases based on clinical parameters.

## Dataset
Source : Kaggel / UCI Machine Learning Repository.
The dataset contains patient records with various thyroid-related features including:
- Thyroid blood tests
- Patient demographic information
- Clinical symptoms

The data exhibits class imbalance, which presented a significant challenge for model development and required appropriate handling techniques.
